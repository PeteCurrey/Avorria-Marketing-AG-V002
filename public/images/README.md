# Avorria Project Media Directory Structure
Place verified project photography, screen recordings, and interface captures in their designated directories:

- `/public/images/hero/`:
  - `hero-desktop.avif` (1800x1200, 3:2 aspect ratio)
  - `hero-desktop.webp` (fallback)
  - `hero-mobile.avif` (900x1125, 4:5 aspect ratio)
  - `hero-mobile.webp` (fallback)

- `/public/images/projects/[slug]/`:
  - `thumbnail.webp` (800x600, 4:3 card showcase)
  - `hero.webp` (1600x900, 16:9 or 21:9 case study hero plate)
  - `gallery-01.webp`, `gallery-02.webp`
  - `interface-01.webp`
  - `mobile-01.webp`

- `/public/images/capabilities/`:
  - `build.webp` (1200x800)
  - `search.webp` (1200x800)
  - `systems.webp` (1200x800)
